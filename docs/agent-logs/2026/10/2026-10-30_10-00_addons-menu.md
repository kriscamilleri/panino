# Add-ons menu in the desktop navbar

- Agent: Claude Code (Opus 5.5)
- Start: 2026-10-30, approximately 09:45
- Status: Implemented and verified locally on `feature/addons-menu`; not committed

## Objective

Kris asked for an **Add-ons** item in the main nav, with the Odoo and GitHub buttons moved out
of Tools into its submenu, and each add-on's buttons separated from the next add-on's.

## Changes Made

- `uiStore.js`: transient `showAddonsMenu` and `toggleAddonsMenu`, included in `isAnyMenuOpen`,
  the one-menu-at-a-time toggle and `closeAllMenus`.
- `Navbar.vue`: **Add-ons** button (`navbar-addons-button`, Puzzle icon) after Tools. It shows
  while an add-on that is on has a toolbar action, and closes the menu if the last one goes away.
- `SubMenuBar.vue`: `<AddonActions surface="toolbar" />` moved from Tools into a new
  `submenu-addons` block.
- `AddonActions.vue`: toolbar actions grouped per add-on in registry order, with a
  `submenu-addons-separator` between groups (none before the first). Test ids renamed from
  `submenu-tools-addon-<id>-<action>` to `submenu-addons-<id>-<action>`. The phone menu is unchanged.
- Docs: `addon-folders.md` §6.2, `addons.md`, `github-integration.md`, `frontend/AGENTS.md`, the
  `add-on-development` skill, both manifests' comments, the GitHub README.

## Tests

- `npm run lint` clean; `npm run test:fe` 85 files, 1047 tests passed; `vite build` passed.

  reads Backup | separator | Odoo, Odoo data, and opening it closes Tools; Backup opens the GitHub
  Backup dialog; with only Odoo on there is no separator.

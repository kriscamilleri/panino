# Dark mode

Agent: Copilot CLI
Started: 2026-08-16 18:10 +02:00
Status: complete

## Objective

Add a persisted Deeply Leafy dark mode with an accessible toggle on the right side of the main
navbar.

## Progress

- Created feature branch `feature/dark-mode` from up-to-date `main`.
- Defined the user journeys, accessibility contract, palette mapping, persistence boundary, and
  security constraints in the active feature spec.
- Mapped shared Tailwind primitives, the desktop/mobile navbar, modal surfaces, and the OverType
  editor's independent color configuration.
- Added a local-storage-backed theme utility and Pinia store, then initialized the selected theme
  before the application shell mounts.
- Added the accessible theme toggle to the right side of the navbar and adapted the OverType
  editor when the preference changes.
- Added Deeply Leafy surface/token remapping for Tailwind-driven pages, dialogs, tables, inputs,
  focus rings, preview content, and editor chrome.
- Browser-verified persisted dark mode at 1280px and 375px using an isolated frontend server.

## Changes Made

- Added the active dark-mode specification.
- Added `themePreference` utility tests, `themeStore` tests, and navbar toggle interaction tests.
- Documented the root theme contract in the UI design system.
